# M02 Notes

## 1.1 Introduction to stochastic proceses

A **stochastic process** is a time-dependent random variable

- Continuous time, \(S(t)\)

- Discrete time, \(S_1, S_2, S_3, ... S_t\)

- Time Series models sample the variable at uniform levels

  - Integer indices
  - Equal Spacing (excluding weekdays / non-business days)
  - Time zero origin

- Discrete Time processes can be constructed by adding increments

Example: \(S_t = S_{t-1} + x_t\)

\(= x_0 + x_1 + x_2 + ... + x_t\)

- Increments can be recovered by differencing

- \(x_t = S_t - S_{t-1}\)

### Time Series Models

- Time series models can be used to model processes that evolve or are observed directly in time
- Often defined, recursively, in terms of prior variables plus an innovation
- The model is "solved" when we can describe or forecast the distribution of values

Examples:

- Cumulative income \(I_1 + I_2 + I_3 + ...\)
- Daily stock price values \(P_t = P_0e^{r_1+r_2+...r_t}\)
- Random walk

## 1.2: Discrete-time random walk model

### Random walk model

- The random walk is the simplest of all time-series models

  \(S_t = z_1 + z_2 + ... + z_T\)

- Each increment is an random IID (Identical, Independent Distributed) variable

  - Independent and identically distributed
  - No dependence on past history
  - Uniform time evolution

- Universality

  - The essential features are independent of many step-level details
  - Easy to generalise for financial applications
  - Appears frequently in other contexts
  - Building block for more complex models

To express the results in terms of a "standard" random variables

- Mean = 0
- Variance = 1
- Correlation = 0 for different times

\(E[z_t] = 0 \\ E[z_t^2] = 1 \\ E[z_tz_{t`}] = 0 \quad \text{if} \  t \neq t`\)

Examples

- Coin toss (+1 or -1 with equal probability) \(z_t = \pm 1, \quad p = \frac{1}{2}\)

Looking at the sum of these identical random variables, as a stochastic processes

\(E[S_t] = E[z_1] + E[z_2] + ... + E[z_t] = 0 \\ Var(S_t) = E[S_t^2] + (E[S_t])^2 \\ Var (S_t) = E[S_t^2] \qquad \text{as} \ E[S_t] = 0\)

\(= \sum_{t=1}^{T}E[z_t^2] + 2\sum_{t < t`}^{} E[z_tz_{t`}] = T \qquad \text{because the cross terms are zero and } E[z_t^2] = 1\)

- So the T-step random walk has variance that grows linearly with T

- The standard deviation (square root) grows as square root of T

## 1.3 Generalised random variable

Generalise the previous \(z_t\) term by introduction two constant parameters

\(r_t = \sigma z_t + \mu\)

- Random variable scaled by \(\sigma\)
- Constant additive piece \(\mu\)

The properties remains the same as the steps are independent in each time period

- Two parameters will measure **risk** and **return**

### Application: asset price returns

- A series of regularly observed stock prices, whose logarithmic returns are defined by

\(r_t \equiv log(\frac{P_t}{P_{t-1}})\)

Logarithm of the price returns, and build the prices as:

\(P_T = P_0e^{r_1 + r_2 + r_3 + ... + r_T}\)

### Generalised random walk model

The expectation operator is linear, to compute the expected return, variance, and covariance is possible with the previous results

\(r_t \equiv \sigma z_t + \mu\)

\(E[r_t] = \mu \\ E[(r_t - \mu)^2] = \sigma^2 \\ E[(r_t - \mu)(r_{t`} - \mu)] = 0 \quad \text{if} \ t \neq t`\)

Looking at the stochastic process generated by the sum of the returns

\(X_T \equiv r_1 + r_2 + ... + r_T = \sum_{t=1}^{T} r^T\)

Since the expectations are linear we can:

\(E[X_T] = E[r_1] + E[r_2] + ... + E[r_T]\)

Also because the returns have identical means since they are IID and there is T variables:

\(E[X_T] = T\mu\)

The variance would be:

\(Var(X_T) = T \sigma^2\)

- The mean and variance of the sum are **linear** in time. They are T times the parameter values of each individual step.

## 2.1 Linear Time Series Models

- To capture **causality** and **correlation** over time, more complex models can be used by combining random walk model

- For example, looking at the Moving Average model which is the MA(1):

  \(r_t = \mu + \sigma z_t + \phi z_{t-1}\)

This defines the random variable as the random walk model and adding a constant \(\phi\), to already realised \(z_{t-1}\) variable, from yesterday to the random walk model which would make this:

- Not IID since each variable would have a different distribution so not identical

In other models, like GARCH for example where the distribution itself is time varying.

- The **Generalised Autoregressive Conditional Heteroscedasticity** model where the volatility is treated as a variable that continuously changes from one time period to the next
- So, the GARCH Model updates today's variance (dictates the width of today's probability distribution) which using a weighted average of a long-run average variance, yesterday's estimated variance and yesterday's actual square return
- The model can then capture the volatility clustering of days naturally

GARCH Model

\(r_t \equiv \mu + \sigma_t \mathcal{z}_t\)

\(= \mu + \epsilon_t, \qquad \epsilon_t \sim \mathcal{N}(0, \sigma_t^2)\)

To model casual influences is to have past values of the random variables itself in the definition of the next term:

For example, there are models such as \(AR(p)\) autoregressive model of order p

\(R_t = c_0 + c_1R_{t-1} + c_2R_{t-2} + ... + c_pR_{t-p} + \sigma \mathcal{z}_t, \quad \mathcal{z}_t \sim IID(0, 1)\)

This basically adds some sort of constant c scalar to each past return up until p lag plus the random walk model where \(z_t\) is an IID Variable, which acts as a kick to the model and \(\sigma\) scalar let's us add a shock factor to the model

Furthermore, we can combine the AR model with MA which would give ARMA model that uses the past returns lagged by p and the MA of last p days to develop a model

\(R_t = c_0 + c_1R_{t-1} + ...+ c_pR_{t-p} \\ + \phi_1z_{t-1} + ... + \phi_qz_{t-q}\)

The distribution of future outcomes can be determined by using linearity, recursion and stationarity

- The time process is **stationary** if the joint distribution of all of it's value is invariant under time translation \(t \rightarrow t + s\)
- It is weakly stationary if the first and second moment (i.e means and covariant) are variant
  - Meaning it doesn't wander far from it's average (weakly stationary)

Looking at AR(1):

\(R_t = c_0 + c_1R_{t-1} + \sigma z_t\)

## 2.2 Solving AR(1)

\(E[R_t] = c_0E[1] + c_1E[R{t-1}] + \sigma E[z_t] \\ = c_0 + c_1E[R_{t-1}]\)

Stationarity means that \(E[R_t] = E[R_{t-1}]\) as stationary it means that it has a finite and constant mean, a constant standard deviation so it becomes the same for today and yesterday the mean

Hence:

\(E[R_t] = \frac{c_0}{1-c_1}\)

Then to simplify,

\(\mu = \frac{c_0}{1-c_1}, \quad \lambda = - c_1\)

So, that AR(1) can be written as suggestive form:

\(R_t - \mu = - \lambda (R_{t-1} - \mu) + \sigma z_t, \quad | \lambda | < 1\)

This model is used for **mean reversion**

- The change in the random variable relative to its mean \(\mu\) is related to the previous period's derivation from the mean.
- For positive value of of the coefficient of \(\lambda\), an excess value in one period leads to a change in one direction, towards the mean, in the following period
- The variance can be computed from stationarity, as can the lagged **autocovariances.**

Mean reversion is statistical tendency for the random variable to pull back towards it's expected mean

### Variance Calculation

To solve for the variance, we have to substitute in the "equation of motion" and expand:

\(\gamma_0 = Var[R_t] = E[(R_t - \mu)^2] \\ = \lambda^2E[(R_{t-1} - \mu)^2] + \sigma E[z_t^2] \\ = \lambda^2 \gamma_0 + \sigma^2\)

since the cross terms drops out due to independence of the \(z_t\) from earlier-time values, \(E[z_t(R_{t-k} - \mu)] = 0\)Therefore,

\(\gamma_0 = \frac{\sigma^2}{1 - \lambda^2}\)

Now, to calculate the covariances of observations taken at two different times

- From stationarity, it depends on k **only**, not t

\(\gamma_k = E[(R_t-\mu)(R_{t-k}-\mu)] \\ = -\lambda E[(R_{t-1} - \mu)(R_{t-k} - \mu)] \\ = -\lambda \gamma_{k-1}\)

So for any k &gt; 0:

\(\gamma_k = (-\lambda)^k \gamma_0 = \frac{(-\lambda)^k}{1-\lambda^2}\sigma^2\)

This would be called / known as lag-k autocovariance coefficient. It relates to the influence of an excess return value at one point in time with value k periods in the past

- Unconditional Expectations are taken with respect to future values
- Conditional Expectations, taken at a fixed point in time, treat past observations as know values rather as random variables

One thing to note is that the autocovariance is not dependent on the mean

## 3.1 Introduction to Monte Carlo Simulation

Use random number generator to simulate stochastic processes

- This provides a test lab, with the "best case" data since it comes from a known distribution
- Because we are generating an ensemble with a large number of hypothetical realizations of a financial process or market
- Approximate exact results by computing statistics over the ensemble
  - Results become more **precise** as simulation size increases
  - Numerical results exist even when close-form results do not
  - Testbed for code and algorithms designed for real-world data

Applications:

- Asset price dynamics
- Option pricing
- Portfolio and risk management

### R code

The three-line process for generating a simple random walk:

```r
z <- runif(n)           # Generate n random uniforms [0,1]
x <- sign(p - z)        # Convert to ±1 coin flips
S <- c(0, cumsum(x))    # Build cumulative path
```

`z <- runif(n)`

- Generates \(n\) independent uniform random numbers between 0 and 1
- Each is the "innovation" or "shock" driving the process
- Independent of all other draws

`x <- sign(p - z)` **(with \(p = 0.5\))**

- Subtracts each uniform from threshold \(p\)
- If \(z < 0.5\): then \((p - z) > 0\) → \(\text{sign}() = +1\)
- If \(z > 0.5\): then \((p - z) < 0\) → \(\text{sign}() = -1\)
- Creates coin flips: \(\pm 1\) with exactly 50/50 probability
- Implements the innovation sequence \(z_t\) from the model

`cumsum(x)`

- Computes cumulative sum: \([x_1, x_1 + x_2, x_1 + x_2 + x_3, ...]\)
- Implements \(S_t = z_1 + z_2 + ... + z_t\)

`S <- c(0, cumsum(x))`

- Prepends 0 to represent starting position at time \(t=0\)
- Creates full path: \(S_0 = 0, S_1, S_2, ..., S_n\)

**Example: \(n = 5\)**

\(z = [0.234, 0.891, 0.456, 0.123, 0.778]\)

\(x = [+1, -1, +1, +1, -1]\)

\(\text{cumsum}(x) = [1, 0, 1, 2, 1]\)

\(S = [0, 1, 0, 1, 2, 1]\)

Path: 0 → 1 → 0 → 1 → 2 → 1

**Theory Verification**

For \(S_t = z_1 + z_2 + ... + z_t\) where each \(z_t = \pm 1\):

\(E[S_t] = 0 \quad \text{(no drift)}\)

\(Var(S_t) = t \quad \text{(variance grows linearly)}\)

\(SD(S_t) = \sqrt{t} \quad \text{(standard deviation grows as } \sqrt{t})\)

Monte Carlo with many paths confirms empirically that these theoretical properties hold.

## 3.3 Analytics of Monte Carlo price paths

### Lognormal Asset Price Model

Asset prices are modelled as **lognormal variables** — their continuously compounded (log) returns are drawn from a normal distribution:

\(r_t = \log(P_t / P_{t-1}) \sim \mathcal{N}(\mu, \sigma^2)\)

This means the price is always positive (since \(P_t = e^{\text{something}}\)), which is a key advantage over additive models.

### Terminal Price & Multi-Period Log Returns

Over \(T\) periods, the **cumulative log return** is the sum of \(T\) i.i.d. normals:

\(r(T) = r_1 + r_2 + \cdots + r_T \sim \mathcal{N}(T\mu,\ T\sigma^2)\)

Mean and variance both **scale linearly** in \(T\) — the same property as the random walk. The **terminal price** is:

\(P_T = P_0 \cdot e^{r(T)}\)

### Expected Simple Return — MGF Derivation

The simple return over the full period is:

\(R = \frac{P_T}{P_0} - 1 = e^{r(T)} - 1\)

Since \(r(T)\) is normal, \(e^{r(T)}\) is lognormal. We use the **Moment Generating Function (MGF)** to find its moments.

**MGF of a Normal:** if \(X \sim \mathcal{N}(\mu, \sigma^2)\), then:

\(M_X(t) = E[e^{tX}] = e^{t\mu + \frac{t^2\sigma^2}{2}}\)

Applying this at \(t = 1\):

\(E[e^{r(T)}] = e^{\mu + \sigma^2/2}\)

Therefore:

\(\boxed{E[R] = e^{\mu + \sigma^2/2} - 1}\)

The \(+\sigma^2/2\) term means the expected simple return exceeds \(e^\mu - 1\) — this is Jensen's inequality: the expectation of a convex function exceeds the function of the expectation.

### Variance of Simple Return — Full Derivation

\(\text{Var}(R) = \text{Var}(e^{r(T)} - 1) = \text{Var}(e^{r(T)})\)

(shifting by a constant doesn't change variance). Using \(\text{Var}(X) = E[X^2] - (E[X])^2\):

**Second raw moment** — MGF at \(t = 2\):

\(E[e^{2r(T)}] = e^{2\mu + 2\sigma^2}\)

**Square of first moment:**

\(\left(e^{\mu + \sigma^2/2}\right)^2 = e^{2\mu + \sigma^2}\)

**Subtracting and factoring:**

\(\text{Var}(R) = e^{2\mu + 2\sigma^2} - e^{2\mu + \sigma^2} = e^{2\mu + \sigma^2}(e^{\sigma^2} - 1)\)

\(\boxed{\text{Var}(R) = e^{2\mu + \sigma^2}(e^{\sigma^2} - 1)}\)

### Simulation Algorithm

| Step | Action |
| --- | --- |
| 1 | Set annualised \(\mu\), \(\sigma\), and time step \(dt = 1/252\) |
| 2 | Scale parameters: each period's return \(\sim \mathcal{N}(\mu \cdot dt,\ \sigma^2 \cdot dt)\) |
| 3 | Draw \(N_t \times N_p\) random normals into matrix \(r\) |
| 4 | Accumulate log returns: \(s_t = s_{t-1} + r_t\) (cumulative sum) |
| 5 | Exponentiate: \(P_t = e^{s_t}\) — ensures prices stay positive (lognormal) |
| 6 | Verify: compare empirical `mean(R)` and `sd(R)` against closed-form analytical formulas |

The small differences between empirical and analytical values are **sampling error**, which shrinks as \(N_p \to \infty\).

## 3.4 Mean reversion simulation and identification

### Simulating an AR(1) Process

### Why AR(1) is Different

Unlike random walks where returns are independent, AR(1) is **recursive**: each return depends on the previous return. This requires **iteration forward in time**—we cannot use matrix algebra shortcuts.

The AR(1) model with mean reversion:

\(R_t - \mu = - \lambda(R_{t-1} - \mu) + \sigma z_t\)

where:

- \(\mu\) = long-run mean (equilibrium level)
- \(\lambda\) = strength of mean reversion (0 to 1)
- \(\sigma z_t\) = random shock

### Key Property: Autocorrelation Reveals Mean Reversion

The autocorrelation at lag 1 shows:

\(\text{Correlation(lag 1)} \approx -\lambda\)

- **Random walk** (\(\lambda = 0\)): No correlation across lags
- **Mean reversion** (\(\lambda = 0.4\)): Lag 1 correlation \(\approx -0.4\)

This **negative correlation** is the signature of mean reversion: if returns spike up today, they tend to pull back down tomorrow (pulled toward the mean).

### Simulation Code

```r
# Parameters
mu <- 0.10         # 10% long-run mean
lambda <- 0.4      # 40% mean reversion strength
sigma <- 0.15      # 15% volatility
Nt <- 252          # 1 year of daily data
Np <- 1000         # number of paths

# Initialize returns matrix
R <- matrix(0, nrow=Nt+1, ncol=Np)

# Iterate forward in time (essential for AR(1))
for (t in 2:(Nt+1)) {
  z <- rnorm(Np, mean=0, sd=1)
  R[t,] <- mu - lambda*(R[t-1,] - mu) + sigma*z
}

# Convert to log prices if needed
log_prices <- rbind(rep(log(100), Np), apply(R, 2, cumsum))
prices <- exp(log_prices)

# Compute autocorrelation function
acf_result <- acf(R[,1], plot=FALSE)
cat("Lag 1 correlation:", acf_result$acf[2], "\n")
cat("Expected (approximately -lambda):", -lambda, "\n")
```

### Why the For Loop is Essential

- Each return **depends on the previous return** through \(-\lambda(R_{t-1} - \mu)\)

- We cannot pre-compute all returns at once (unlike random walk)

- We must build the process sequentially in time

  This is fundamental to recursive/autoregressive models

### Properties of Mean Reversion

The parameter \(\lambda\) controls behavior:

- \(\lambda = 0\) → recovers random walk (no mean reversion)
- \(\lambda = 0.4\) → moderate mean reversion
- \(\lambda = 0.9\) → strong mean reversion
- \(|\lambda| < 1\) required for stationarity

The drift \(\mu\) affects the **level** but **not the correlations**. The volatility \(\sigma\) controls randomness relative to the restoring force.

### Model Identification with Monte Carlo

The real power: we can **test if we can identify which model we have**

- Generate data from AR(1) with known parameters
- Plot sample paths → hard to tell by eye if mean reverting
- Compute the ACF (autocorrelation function) → clearly shows lag-1 signature
- Compare to random walk ACF → lag-1 near zero

This answers the crucial financial question: **Is this process mean reverting or random?**

In real markets, we never know the true data generating process. Monte Carlo lets us practice identifying models in a controlled setting before analyzing real data.

## Exercise 2: Solving a time series model

:::toggle Let a stochastic process be defined by
Formula:

\(X_t = \epsilon_t + \theta \epsilon_{t-2}, \quad \epsilon_t = \sigma z_t\)

\
where \(z_t\) are independent, standardized random variables. Is \(X_t\) stationary? Find the mean, variance, and autocovariance function.

**Stationarity**

Yes, \(X_t\) is weakly stationary. The mean and autocovariances (derived below) are finite constants that depend only on the lag, not on \(t\). Since \(X_t\) is a finite linear combination of the \(\epsilon_t\) terms, and each \(\epsilon_t = \sigma z_t\) with the \(z_t\) IID standardized, the distributional properties are time-invariant.

**Mean**

Since \(E[z_t] = 0\) for all \(t\):

\(E[X_t] = E[\epsilon_t] + \theta E[\epsilon_{t-2}] = \sigma E[z_t] + \theta\sigma E[z_{t-2}] = 0\)

**Variance**

Since \(E[X_t] = 0\), we have \(\text{Var}(X_t) = E[X_t^2]\). Expanding:

\(E[X_t^2] = E[(\epsilon_t + \theta\epsilon_{t-2})^2] = E[\epsilon_t^2] + 2\theta\,E[\epsilon_t\epsilon_{t-2}] + \theta^2 E[\epsilon_{t-2}^2]\)

Since \(z_t\) are independent, \(E[\epsilon_t \epsilon_{t-2}] = \sigma^2 E[z_t]E[z_{t-2}] = 0\), and \(E[\epsilon_t^2] = \sigma^2\). Therefore:

\(\boxed{\text{Var}(X_t) = \sigma^2(1 + \theta^2)}\)

**Autocovariance Function**

\(\gamma_k = E[X_t X_{t-k}] = E[(\epsilon_t + \theta\epsilon_{t-2})(\epsilon_{t-k} + \theta\epsilon_{t-k-2})]\)

Expanding the product and using independence of the \(\epsilon\) terms (so \(E[\epsilon_i \epsilon_j] = \sigma^2\) if \(i = j\), else 0):

- **\(k = 0\):** \(\gamma_0 = \sigma^2 + \theta^2\sigma^2 = \sigma^2(1 + \theta^2)\) ✓
- **\(k = 1\):** All index pairs are distinct \(\Rightarrow \gamma_1 = 0\)
- **\(k = 2\):** The \(\theta E[\epsilon_{t-2}^2]\) term survives: \(\gamma_2 = \theta\sigma^2\)
- **\(|k| \geq 3\):** All index pairs are distinct \(\Rightarrow \gamma_k = 0\)

Summary:

\(\gamma_k = \begin{cases} \sigma^2(1 + \theta^2) & k = 0 \\\\ \theta\sigma^2 & |k| = 2 \\\\ 0 & \text{otherwise} \end{cases}\)

> **Note:** This is an **MA(2)** process with the lag-1 coefficient forced to zero — only the lag-2 shock \(\epsilon_{t-2}\) enters. The autocovariance cuts off exactly at lag 2, which is the defining feature of a finite-order MA process.

:::

## Exercise 3: Average of observations (extension of Exercise 2)

:::toggle Define a random variable \(A\) as the average of the next four observations of the \(X_t\) process from Exercise 2:
Formula:

\(A = \frac{1}{4}(X_1 + X_2 + X_3 + X_4)\)

What are the mean and variance of \(A\)?

**Mean**

By linearity of expectation, and since \(E[X_t] = 0\) for all \(t\):

\(E[A] = \frac{1}{4}(E[X_1] + E[X_2] + E[X_3] + E[X_4]) = 0\)

**Variance**

The variance of a scaled sum expands over all pairs using the autocovariance function:

\(\text{Var}(A) = \frac{1}{16}\,\text{Var}(X_1 + X_2 + X_3 + X_4) = \frac{1}{16}\sum_{i=1}^{4}\sum_{j=1}^{4} \gamma_{|i-j|}\)

Using the autocovariance from Exercise 2 — \(\gamma_0 = \sigma^2(1+\theta^2)\), \(\gamma_2 = \theta\sigma^2\), all others zero — count each lag group across all 16 pairs:

The 4 lag-2 pairs are \((1,3),(3,1),(2,4),(4,2)\) — exactly where the MA(2) cross-covariance is non-zero.

Summing all contributions:

\(\sum_{i,j}\gamma_{|i-j|} = 4\sigma^2(1+\theta^2) + 4\theta\sigma^2 = 4\sigma^2(1 + \theta + \theta^2)\)

Therefore:

\(\boxed{\text{Var}(A) = \frac{\sigma^2(1 + \theta + \theta^2)}{4}}\)

> **Note:** Compared to a single observation \(\text{Var}(X_t) = \sigma^2(1+\theta^2)\), averaging over 4 reduces variance by roughly a factor of 4. But the \(+\,\theta\) term shows that the lag-2 correlations inflate the variance relative to the independent case. When \(\theta = 0\) (pure white noise), we recover \(\text{Var}(A) = \sigma^2/4\) exactly.

## Exercise 4: AR(1) as an infinite-order MA process

:::toggle Use recursion to show that the AR(1) process can be expressed as an MA process of infinite order.
Setup

Start with the AR(1):

\(R_t - \mu = -\lambda(R_{t-1} - \mu) + \sigma z_t\)

Define \(y_t = \frac{R_t - \mu}{\sigma}\) to strip the scaling, giving:

\(y_t = z_t - \lambda\, y_{t-1}\)

The goal is to eliminate all \(y\) terms on the right, leaving only \(z\)'s at different lags.

**Recursive substitution**

Wherever \(y_{t-1}\) appears, substitute the same equation shifted back one period:

\(y_t = z_t - \lambda(z_{t-1} - \lambda\, y_{t-2}) = z_t - \lambda z_{t-1} + \lambda^2 y_{t-2}\)

Substitute again for \(y_{t-2}\):

\(y_t = z_t - \lambda z_{t-1} + \lambda^2 z_{t-2} - \lambda^3 y_{t-3}\)

Each round pushes the residual \(y\) term one step further into the past, multiplied by an extra \(\lambda\). Since \(|\lambda| < 1\), the residual \(\lambda^k y_{t-k} \to 0\) as \(k \to \infty\).

**Result: MA(∞) representation**

Running the recursion infinitely yields:

\(\boxed{y_t = \sum_{k=0}^{\infty} (-\lambda)^k z_{t-k}}\)

Restoring original variables:

\(R_t = \mu + \\sigma \\sum_{k=0}^{\\infty} (-\\lambda)^k z_{t-k}\)

**Key takeaways**

- **Causality** — \(R_t\) depends only on past and present shocks \(z_t, z_{t-1}, \\ldots\), never future ones. This is a semi-infinite sum into the past only.
- **Convergence** — the \(|\\lambda| < 1\) stationarity condition ensures coefficients \((-\\lambda)^k\) shrink to zero. Without it the sum blows up.
- **Cross-term independence** — since \(R_t\) is built entirely from \(z_s\) with \(s \\leq t\), any future shock \(z_s\) with \(s > t\) is uncorrelated with \(R_t\). This is why \(E[z_s(R_t - \\mu)] = 0\) for \(s > t\) — cross terms drop out cleanly in variance and autocovariance derivations.

:::

## Multivariate Time Series (VAR Models)

[[linear-algebra-prereqs|linear algebra prereqs]] [[var-models|var models]]

The core problem is that when you have multiple variables (say \(x_t\) and \(y_t\)) that influence each other, you can't solve them independently — they're coupled. The method uses linear algebra to **decouple** them.

### Step 1 — Stack into a Vector AR System

Group the variables into a vector and write the system as:

\(C_t = M \cdot C_{t-1} + \sigma \eta_t\)

where \(M\) is the coefficient matrix and \(\eta_t\) is a vector of independent noise terms.

### Step 2 — Diagonalize \(M\)

Perform an eigenvalue decomposition:

\(M = V \gamma V^{-1}\)

where \(V\) is the matrix of eigenvectors and \(\gamma\) is the diagonal matrix of eigenvalues. The eigenvectors represent the **natural independent modes** of the system.

### Step 3 — Change Variables to Decouple

Multiply through by \(V^{-1}\) to "unshuffle" the variables. This transforms \(N\) coupled equations into \(N\) completely independent univariate equations — each one is just a standard AR(1) you already know how to solve.

### Step 4 — Solve then Invert

Solve each univariate equation independently, then apply \(V\) to transform back to the original variables.

> **Key insight:** Eigenvectors reveal the hidden independent combinations of your variables that the system naturally evolves along. This technique works when \(M\) is full rank and invertible, and the noise enters with a diagonal coefficient.

### Worked Example: 2×2 Coupled System (HW2)

A concrete example of the VAR method above. The system is:

\(x_t = \lambda y_{t-1} + \sigma z_t\)

\(y_t = \lambda x_{t-1} + \sigma w_t\)

where \(z_t, w_t \sim \mathcal{N}(0,1)\) are independent with \(E[z_t w_s] = 0\) for all \(t, s\), and \(E[z_t z_s] = E[w_t w_s] = \delta_{ts}\).

**Step 1 — Write in matrix form**

Stack into a vector \(C_t = \begin{pmatrix} x_t \\ y_t \end{pmatrix}\):

\(C_t = M C_{t-1} + \sigma \eta_t, \quad M = \begin{pmatrix} 0 & \lambda \\ \lambda & 0 \end{pmatrix}, \quad \eta_t = \begin{pmatrix} z_t \\ w_t \end{pmatrix}\)

**Step 2 — Find eigenvalues of \(M\)**

\(\det(M - \gamma I) = 0 \implies \gamma^2 - \lambda^2 = 0 \implies \gamma = \pm\lambda\)

So the two eigenvalues are \(\gamma_1 = +\lambda\) and \(\gamma_2 = -\lambda\).

**Step 3 — Find eigenvectors**

For \(\gamma_1 = +\lambda\): eigenvector \(v_1 = \frac{1}{\sqrt{2}}\begin{pmatrix}1\\1\end{pmatrix}\)

For \(\gamma_2 = -\lambda\): eigenvector \(v_2 = \frac{1}{\sqrt{2}}\begin{pmatrix}1\\-1\end{pmatrix}\)

So \(V = \frac{1}{\sqrt{2}}\begin{pmatrix}1 & 1\\1 & -1\end{pmatrix}\)

**Step 4 — Change to decoupled variables**

Define \(u_t = V^{-1} C_t\), i.e. the natural combinations:

\(u_t = x_t + y_t \quad \text{(sum mode, eigenvalue } +\lambda\text{)}\)

\(v_t = x_t - y_t \quad \text{(difference mode, eigenvalue } -\lambda\text{)}\)

Each now satisfies an independent AR(1):

\(u_t = \lambda u_{t-1} + \sigma(z_t + w_t)\)

\(v_t = -\lambda v_{t-1} + \sigma(z_t - w_t)\)

**Step 5 — Solve each independently**

These are standard AR(1) processes. Using the stationarity results from §2.2:

\(\text{Var}(u_t) = \frac{2\sigma^2}{1 - \lambda^2}, \quad \text{Var}(v_t) = \frac{2\sigma^2}{1 - \lambda^2}\)

**Step 6 — Invert back**

Since \(x_t = \frac{1}{2}(u_t + v_t)\) and \(y_t = \frac{1}{2}(u_t - v_t)\):

\(\text{Var}(x_t) = \text{Var}(y_t) = \frac{\sigma^2}{1 - \lambda^2}\)

> **Intuition:** The sum \(x+y\) and difference \(x-y\) are the natural modes — the system rotates between them. Mean reversion strength is \(|\lambda|\) for both, but the sum mode reverts toward zero with coefficient \(+\lambda\) while the difference mode alternates with \(-\lambda\).

## Common Mistakes

### Autocovariance vs Second Moment (HW1 Q1c)

**Mistake:** Confusing \(E[r_t r_{t-k}]\) (second moment) with \(\gamma_k = \text{Cov}(r_t, r_{t-k})\) (autocovariance).

**Correct definition:**

\(\gamma_k = E[(r_t - \mu)(r_{t-k} - \mu)]\)

They are related by:

\(\gamma_k = E[r_t r_{t-k}] - \mu^2\)

**Why this matters:** For the MA(1) model \(r_t = \epsilon_t + a\epsilon_{t-1} + b\) with mean \(\mu = b\), for \(k \geq 2\) there are no overlapping innovation terms so:

\(E[r_t r_{t-k}] = b^2 \quad \text{but} \quad \gamma_k = b^2 - b^2 = 0\)

The autocovariance is **zero**, not \(b^2\). The \(b^2\) cancels because autocovariance always subtracts \(\mu^2\). When the mean is zero this distinction disappears, but when \(\mu \neq 0\) you must demean first.
